# Tabularium

Tabularium 是可独立部署的自托管加密笔记同步服务器，提供账户、笔记库、设备权限和同步接口，并计划内置可在网页端对话的 AI 笔记管理员。Obsidian 插件是接入服务器的客户端。采用客户端加解密、服务端网关和内网 CouchDB，不开放公开注册。

P0 基线、P1 同步网关、服务器管理控制台、停机备份恢复、升级回退和 vault 重建已实现，可通过 Compose 独立启动。浏览器可管理账户、笔记库和设备，查看用量、运行状态及操作记录；备份可恢复到新的 Compose 项目，真实客户端在恢复实例上续传；升级先在隔离副本上试运行，可回退到升级前的镜像和数据。插件改造作为配套客户端工作，网页笔记不属于服务器首版的必要交付。
