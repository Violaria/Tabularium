# Tabularium

Tabularium 是可独立部署的自托管加密笔记同步服务器，提供账户、笔记库、设备权限和同步接口。Obsidian 插件是接入服务器的客户端。采用客户端加解密、服务端网关和内网 CouchDB，不开放公开注册。

P0 基线、P1 同步网关与服务器管理控制台已实现，可通过 Compose 独立启动。浏览器可管理账户、笔记库和设备，查看用量、运行状态及操作记录；12 个网关同步场景通过。下一阶段实现服务器备份与恢复。插件改造作为配套客户端工作，网页笔记不属于服务器首版的必要交付。
